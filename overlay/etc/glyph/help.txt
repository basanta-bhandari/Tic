ZENITH OS QUICK REFERENCE
=========================

NAVIGATION
  zenith                main application launcher
  glyph-control         settings and system tools
  imperium ACTION       compositor, panes, tabs, overlays, and native media
  kage                  Fish-compatible interactive shell
  glyph-theme           choose a coordinated Kitty palette
  glyph-wallpaper       install/use an indexed wallpaper from GitHub
  arca                  TUI package management
  glyph-open PATH       open a file with a suitable TUI
  glyph-doctor          health and update report

  Esc                   back or close a dialog
  Tab / arrows          move through controls
  Enter                 activate the selected item
  Ctrl+Alt+F2..F6       switch to another virtual console

SHELL
  Kage is the Fish-compatible login shell. Suggestions come from history; use
  the right arrow to accept one. Tab opens searchable completion. `help` opens
  Kage/Fish help and
  `tldr COMMAND` shows task-oriented examples.

  Common abbreviations:
    ll      eza -la --group-directories-first
    gs      git status
    v       nvim
    fm      yazi
    update  sudo pacman -Syu

WORKSPACES
  Ctrl+Shift+Enter       new vertical Kitty split
  Ctrl+Shift+\           new horizontal Kitty split
  Ctrl+Shift+T           new workspace tab
  Ctrl+Shift+Space       Zenith launcher overlay
  Ctrl+Shift+O           surface overview

  Run `zellij` when a detachable session must survive Kitty or Sway.

FILES
  Yazi uses arrows or h/j/k/l to navigate, Enter/l to open, q to leave, and ?
  for help. `glyph-open` handles text, Markdown, tables, PDFs, images, audio,
  video, HTML, archives, and directories. In Kitty, images use its graphics
  protocol; under Wayland, video opens in VLC.

WALLPAPERS
  glyph-wallpaper install            browse all indexed GitHub categories
  glyph-wallpaper install nord       browse the nord category
  glyph-wallpaper list nature        list nature files
  glyph-wallpaper use                choose an already downloaded image

PACKAGES
  Use `arca`, or Pacman directly:
    sudo pacman -Syu            update the system
    pacman -Ss WORD             search repositories
    sudo pacman -S PACKAGE      install
    sudo pacman -Rns PACKAGE    remove with unused dependencies

RECOVERY
  The launcher is optional. Press Esc and choose Exit to reach Kage, set
  ZENITH_NO_LAUNCH=1 (legacy: GLYPH_NO_LAUNCH=1), or switch to another TTY.
  Standard Arch documentation and
  commands always remain valid.
